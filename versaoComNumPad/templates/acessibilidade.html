♿ Sistema de Estoque Acessível

Este sistema foi desenvolvido seguindo as Diretrizes de Acessibilidade WCAG 2.1 Nível AAA, garantindo que todas as pessoas possam utilizá-lo com facilidade e conforto.

🎯 Recursos de Acessibilidade Implementados

👁️ Para Pessoas com Deficiência Visual

  • Texto Grande: Tamanho mínimo de 18px para melhor legibilidade
  • Bordas Visíveis: Todas as áreas clicáveis têm bordas grossas e bem definidas
  • Ícones com Texto: Todos os ícones têm descrição em texto
  • Foco Visível: Indicador de foco com borda verde grossa de 3px

⌨️ Para Navegação por Teclado

  • Tab: Navegar para o próximo elemento
  • Shift + Tab: Navegar para o elemento anterior
  • Enter ou Espaço: Ativar botões e links
  • Escape: Fechar modais e menus
  • Setas: Navegar em listas e menus
💡 Dica: Pressione Tab para navegar pelo site sem usar o mouse!

🎨 Paleta de Cores Acessível

Todas as cores foram cuidadosamente selecionadas para garantir contraste adequado:

Texto Principal

Contraste: 14:1 ✓

Botões

Contraste: 7:1 ✓

🌈 Cores Principais:

  • Verde Escuro (#4D7033): Botões e destaques importantes
  • Cinza Claro (#F0F0F0): Fundo principal
  • Branco (#FFFFFF): Cards e áreas de conteúdo
  • Preto Suave (#1A1A1A): Textos e ícones

📏 Tamanhos e Espaçamentos

  • Botões: Mínimo de 44x44 pixels (padrão de acessibilidade)
  • Texto Base: 18 pixels (maior que o padrão web)
  • Espaçamento: Generoso entre elementos para facilitar cliques
  • Linha de Texto: Altura de 1.6 para facilitar leitura
  • Largura Máxima: 70 caracteres por linha para conforto visual

🔊 Compatibilidade com Leitores de Tela

O sistema é totalmente compatível com:

  • NVDA: Leitor de tela gratuito para Windows
  • JAWS: Leitor de tela profissional
  • VoiceOver: Leitor nativo do iOS e macOS
  • TalkBack: Leitor nativo do Android
✓ Recursos para leitores de tela:
  • Textos alternativos em todas as imagens
  • Rótulos descritivos em todos os campos
  • Marcação semântica HTML5
  • Anúncios de estado e mudanças

💡 Dicas de Uso

Para usuários com baixa visão:

  • Use o zoom do navegador (Ctrl + ou Cmd +) sem perder funcionalidade
  • O foco sempre estará visível com uma borda verde grossa
  • Todos os textos são grandes e em cores de alto contraste

Para usuários com pouca experiência:

  • Todos os botões têm ícones E texto explicativo
  • As mensagens de erro são claras e sugerem soluções
  • Os formulários têm validação e dicas de preenchimento
  • A navegação é simples e consistente em todas as páginas
